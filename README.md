# denuncia_openai

Expediente técnico-documental público solicitado por Facundo Firmenich sobre fallos agénticos observados entre el 12 de julio y el 11 de agosto de 2026.

## Contenido

- Superdocumento de auditoría e inculpación factual agéntica.
- Índice de 67 tareas seleccionadas dentro de la ventana.
- 230 episodios adversos con contexto.
- Transcripción de 2018 mensajes de las tareas nativas aportadas.
- Registro maestro, manifiestos SHA-256, método reproducible y adjuntos.

## Redacción de seguridad

El repositorio es público. Se preservan todos los casos y mensajes sustantivos, pero credenciales, tokens y llaves privadas se sustituyen por marcadores con el SHA-256 del valor retirado. Los rollouts nativos crudos que contienen payloads de herramientas y secretos permanecen bajo custodia local; sus nombres, bytes y hashes constan en `PUBLICATION_REDACTION_MANIFEST.json`.

## Frontera jurídica

El expediente atribuye conductas operativas al agente a partir de tareas, mensajes y artefactos. No constituye por sí mismo sentencia, peritaje jurídico independiente ni determinación de responsabilidad penal o civil de OpenAI. Es material para revisión por Fable5, asesoría, peritaje o autoridad competente.
